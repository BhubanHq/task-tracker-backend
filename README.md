# Task Tracker Backend

This is a simple backend API for managing tasks. It is built as part of the Task Tracker project.

Project URL: https://roadmap.sh/projects/task-tracker

## Features

* Create a new task
* View all tasks
* Update a task
* Delete a task
* Mark tasks as complete or incomplete

## Tech Stack

* Node.js
* Express.js

## Installation

Clone the repository:
git clone https://github.com/BhubanHq/task-tracker-backend.git

Go to the project directory:
cd task-tracker-backend

Install dependencies:
npm install

## Run the Project

Start the server:
npm start

Server will run on:
http://localhost:3000

## API Endpoints

* GET /tasks → Get all tasks
* POST /tasks → Create a new task
* PUT /tasks/:id → Update a task
* DELETE /tasks/:id → Delete a task
